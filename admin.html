Gérez les articles du blog, les produits de la boutique, les commandes et les réglages de paiement. Ces changements sont enregistrés sur cet appareil et seront envoyés à votre base distante dès que la synchronisation sera activée (voir js/sync.js).

⚠️ Cette page n'a aucune protection réelle : le mot de passe est vérifié uniquement dans le navigateur et reste visible dans le code source (js/admin.js). Elle est suffisante pour éviter les visites accidentelles, mais pas pour protéger des données sensibles. Ne partagez pas ce lien publiquement, et prévoyez une vraie authentification côté serveur avant d'y stocker des informations confidentielles.
